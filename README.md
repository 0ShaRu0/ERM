# 이음 장비 대여 관리

모바일과 PC에서 각각 설치하여 사용하는 **기기별 독립 웹앱**입니다. 장비·대여자·대여 이력·사진·통계를 기기 안에 저장하며, 평소 실행에는 서버나 인터넷 연결이 필요 없습니다. USB를 연결했을 때 양쪽 기록을 동기화할 수 있습니다.

- 배포 파일: `이음-독립앱.zip` 또는 `standalone/`
- 설치·백업·기존 데이터 이전: [독립앱 사용 안내](독립앱_사용안내.md)
- 재빌드: `python tools/build_standalone.py`

**Android:** USB 디버깅을 켜고 PC에 연결한 뒤 `Android_USB_최초설치.bat`을 실행하세요. 휴대폰에서 앱을 설치하고 오프라인 준비를 마치면 USB를 빼도 됩니다.

**PC:** `PC_앱_최초설치.bat`을 실행하고 Chrome/Edge의 앱 설치를 선택하세요. 설치 완료 후 설치 창을 종료합니다. 두 설치 도구는 Windows Python을 사용합니다.

**USB 동기화:** `USB_데이터_동기화.bat` 실행 → PC/휴대폰 양쪽의 `기기 · 백업` → `USB로 양쪽 데이터 동기화`. 양쪽 저장 완료 후 도구를 종료하고 USB를 분리하세요. 신규 기록을 합치고 삭제·반납을 반영하며, 수량 충돌은 자동 반영하지 않습니다.

인터넷 호스팅은 필요 없습니다. `이음-USB설치.zip`에 앱과 최초 설치 도구를 묶었습니다. 최초 설치 때만 파일 전달용 서버를 잠시 열고, 이후에는 기기의 설치 앱으로 독립 실행합니다.

`main.py`, `web_app.py`, 기존 실행 배치 파일은 이전 PC 서버/데스크톱 버전입니다. 독립 앱을 쓰려면 위 배포 파일로 설치하세요. 기존 `rental.db`와 이미지 파일은 그대로 유지됩니다.
