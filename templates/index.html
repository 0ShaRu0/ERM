현장 기기를 연결하는 법

  1. 같은 Wi-Fi 사용

    PC와 안드로이드 기기를 같은 Wi-Fi에 연결한 뒤, 모바일 브라우저에서 위 서버 주소를 여세요.

  2. USB 테더링 사용

    Wi-Fi가 없다면 안드로이드의 USB 테더링을 켜고, PC가 안내하는 네트워크 주소로 접속하세요.

  3. 오프라인 앱 설치

    USB 연결의 localhost 주소 또는 신뢰된 HTTPS 주소에서 ‘앱 설치’를 선택하세요. 일반 Wi-Fi HTTP는 열린 화면에서만 오프라인 기록이 가능합니다.

오프라인 작업은 이 기기에만 보관됩니다. 서버 연결 전에 브라우저 데이터를 삭제하지 마세요.
